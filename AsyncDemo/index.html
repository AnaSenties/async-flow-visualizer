Interactive JavaScript Asynchrony Demo

1. Callbacks

A callback is a function passed as an argument to another function, to be executed at some point.

2. Promises

A promise is an object representing a future value. It's consumed with .then(), .catch(), and .finally().

3. Async/Await

async/await is syntactic sugar over promises. It allows writing asynchronous code that reads like synchronous code.

4. Event Loop

The Event Loop executes synchronous code, then Microtasks (promises), and finally Tasks (setTimeout).
